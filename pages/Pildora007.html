Manejo de Errores

Tolerancia y recuperacion de fallos

En sistemas reactivos, el manejo de errores es fundamental para mantener el flujo sin interrupciones.

  • onErrorResume: Permite reemplazar una secuencia con valores alternativos cuando ocurre un error.
  • onErrorReturn: Devuelve un valor por defecto al ocurrir un error.
  • retry: Reintenta la operacion un numero de veces configurado.
  • retryWhen: Define una estrategia personalizada de reintentos.

Ejemplo: Recuperacion de error

Flux data = Flux.just("1", "a", "3")
    .map(Integer::parseInt)
    .onErrorResume(e -> Flux.just(0));

Esencia

Un sistema reactivo debe anticipar y gestionar errores para seguir operando sin bloqueos.
